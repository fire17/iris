How it was run

Six dynamic ultracode workflows, held 3–5 deep the whole time. Every agent() call carried an explicit model: 'opus'; the naked-spawn and non-opus greps returned empty before each launch.

WorkflowAgentsWhat it did

The method that did the work. Nothing in the README was written from the project's own documentation. Every skeptic was told the same thing: docs state intent and may be stale; code and live HTTP responses are evidence. That single instruction is what caught the Cinemeta auto-install, the web-seed reality of the demo row, the whisper probe, and the addon lane-escalation defect — four things the repo's own README.md, ARCHITECTURE.md and UNKNOWNS.md would each have let through.

One grep note worth keeping. js/addons.js contains a non-UTF8 byte, so plain grep treats it as binary and silently matches nothing. Any audit that greps it without -a will miss the Cinemeta auto-install entirely — which is exactly how a "no API" claim survives an audit that looked like it was done properly.
