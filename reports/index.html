the law · fire17, non-negotiable

Any node we run may relay handshakes and signaling only. It must never carry file bytes. Files flow peer→browser directly, or not through us. A bridge that re-serves torrent bytes to the browser violates the law and is a failed result — even if it "works".

The mission in one screen

Two columns, one honest boundary. On the left, what genuinely plays browser-only with zero node in the byte path. On the right, what physically cannot — and exactly why.

Plays browser-only · law-compliant

bytes flow peer→browser, no node in the path

  • Browser-to-browser WebRTC torrent. Two browsers exchange the file over a direct DataChannel; our signaling node is SIGKILLed the instant the channel opens and the full 68,086,404-byte clip still streams to 100%. Node carried 0 file bytes.
  • Self-sustaining swarm. Once one browser holds the bytes, the swarm survives with no tracker and no original seeder — pure browser-to-browser reseed.
  • Self-seeded catalog over a plain static host (HTTP Range web-seed), played through the real player with no backend.
  • Live subtitles from OpenSubtitles v3 + every installed addon, SRT/SSA/VTT → WebVTT, language picker, offset, remembered — no proxy of ours.
  • User-brings-the-file seeding, and third-party HTTP mirrors — the two genuine law-compliant boundaries.

Physically cannot · and why

arbitrary TCP-only magnet, no local copy

  • An arbitrary TCP/uTP Torrentio magnet cannot play browser-only. A browser reaches bytes over exactly four transports — WebRTC, WebSocket, WebTransport, HTTP — and a raw BitTorrent peer speaks none of them. There is no fifth transport.
  • Signaling can't fix it. A relay changes introductions, not the wire protocol. The only ICE path to a non-STUN host is TURN, which relays the bytes — a forbidden byte-path node.
  • The bootstrap paradox. A browser can only seed over WebRTC content it already holds; for TCP-only content the genesis seeder could only have gotten it from a byte-path node. No such node ⇒ no browser swarm ever forms.
  • Measured: the target swarm was fully alive over TCP/uTP (54 seeders) yet exposed 0 browser-reachable WebRTC seeders.
  • The "torrentio bridge" is not a win — it leeched 99,532,800 B through a node we run and re-served them. That is the law-violation the verdict names, not a browser-first success.
